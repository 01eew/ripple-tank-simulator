# 🌊 Ripple Tank Simulator — محاكي حوض الأمواج التفاعلي

محاكي أمواج تفاعلي ثنائي وثلاثي الأبعاد مبني بـ Flutter & Dart بدون مكتبات خارجية.

**برمجة وتطوير:** حسين خالد حميد — هندسة الأمن السيبراني، جامعة المعقل
**أستاذ المادة:** د. أحمد دنقل

- محرك FDTD على شبكة 180×180 (Float32List / Uint8List)
- الانعكاس، الحيود (شق مفرد ومزدوج)، التشتت، الانكسار والامتصاص
- عرض 2D وعرض 3D بشبكة ارتفاعات (ui.Vertices) وكاميرا Pitch & Yaw
- سحب وإفلات للمصادر والعوائق، ومجسات قياس (Oscilloscope)

الكود المصدري داخل `project.tar.gz`، ويُبنى ملف IPA تلقائياً عبر GitHub Actions.
